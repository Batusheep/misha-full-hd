# «Миша + Туман Full HD»

Рабочий вариант — [index.html](index.html). Разметка, стили и скрипты находятся в одном HTML. Изменения дизайна этого варианта хранятся здесь и в общих правилах затронутых компонентов.

- Для полноразмерных панелей используем общие [правила сайдбаров](../docs/components/sidebar.md). Проверенные примеры здесь — фильтр предложений и редактирование профиля.
- Заявка на участие проходит внутри страницы предложения. Полноразмерные шаги заявки используют общую страницу выбранного инструмента.
- В [отчётах и снимках](../qa/misha-full-hd/README.md) перечислены проверенные экранные состояния и ширины.

Референс для конфигуратора и пресетов — [«Коробка-миша.html»](../reference/Коробка-миша.html).

Порядок работы — [инструкция для HTML, CSS и JS](../WORKFLOW.md).

У страницы зарезервировано место для системной полосы прокрутки через `scrollbar-gutter: stable` на `html`. Это сохраняет ширину контента при переключении коротких и длинных вкладок. [Проверка геометрии](../qa/misha-full-hd/profile-scrollbar-gutter.json).

В профиле телефон и почта собраны на отдельной вкладке «Контакты». В общем сайдбаре каждый контакт можно добавить, изменить и подтвердить кодом; новое значение отображается после подтверждения. Отправка и проверка кода имитируются в прототипе. Кнопка «Заполнить данные» ведёт к персональным данным для проверки.

В карточке профиля имя и фамилия расположены в две строки; переключатель типа профиля доступен на каждой вкладке и синхронизирован с меню аккаунта.

Центр уведомлений поддерживает список и таблицу, фильтры по типу, статусу и периоду, поиск, сортировку таблицы и раскрытие подробностей. Ответ поддержке — локальный сценарий прототипа. Фотография профиля хранится в браузере и доступна для замены и удаления.

На обзоре сводка разделяет стоимость портфеля, показатели и действия; график заполняет доступную высоту карточки.

Для акций в каталоге показываем цену акции, если она указана; в колонке доходности таблицы ставим прочерк. Минимальную сумму вложения не принимаем за цену акции.

Вкладки профиля и предложения используют общий переключатель оформления. Плитки каталога сохраняют ширину при малом числе предложений; в заявке на акции сумма округляется вниз до целого количества акций.
